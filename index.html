CSS Terapan (Realtime Update)
header {
  position: sticky;
  top: 0px;
  z-index: 100;
  width: 100%;
}

footer {
  position: sticky;
  bottom: 0px;
  z-index: 100;
  width: 100%;
}

.card {
  position: relative; /* Menjadi referensi titik koordinat anak */
}

.card-badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
Kaidah Emas Positioning
1. static: Aliran normal bawaan HTML. Mengabaikan top/bottom/left/right/z-index.
2. relative: Tetap di aliran normal, bisa digeser koordinat, dan menjadi "jangkar" acuan bagi elemen anak bernilai absolute!
3. absolute: Keluar dari aliran normal, melayang relatif terhadap elemen leluhur terdekat yang memiliki position (selain static).
4. fixed: Keluar dari aliran normal, mengunci mati terhadap jendela layar (viewport).
5. sticky: Seperti relative saat biasa, lalu otomatis "menempel" seperti fixed begitu mencapai ambang batas top/bottom saat di-scroll.
